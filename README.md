# Federated learning in intelligent transportation systems supplementary materials

This repository provides Supplementary Materials S1–S7 for the manuscript **The Role of Federated Learning in Intelligent Transportation Systems: Taxonomy, Emerging Trends, Applications, Open Challenges, and Future Research Directions**.

## Documents

| Supplement | Contents | File |
| --- | --- | --- |
| S1 | Search strategy and study selection | [Download Word document](S1_Search_Strategy.docx) |
| S2 | Corpus characteristics and annual publication output | [Download Word document](S2_Corpus_Metadata.docx) |
| S3 | Taxonomy and coding framework | [Download Word document](S3_Taxonomy_Codebook.docx) |
| S4 | Inter-reviewer coding agreement | [Download Word document](S4_Coding_Reliability.docx) |
| S5 | Selection framework for detailed appraisal | [Download Word document](S5_Study_Selection.docx) |
| S6 | Critical appraisal framework and study coding | [Download Word document](S6_Critical_Appraisal.docx) |
| S7 | Sensitivity to search boundaries | [Download Word document](S7_Sensitivity_Analysis.docx) |

The seven Word documents report the search strategy, corpus summaries, classification framework, coding agreement, appraisal selection and coding, and search-scope sensitivity comparisons. Their scope and methodological qualifications are described in the individual supplements.
